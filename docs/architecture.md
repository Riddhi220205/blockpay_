# System Architecture

The Blockchain-Based Recurring Payment Subscription System consists of the following components:

1. User Wallet
Users connect their crypto wallet (e.g., MetaMask) to interact with the system and authorize subscription payments.

2. Frontend Application
A web interface where users can view subscription plans, subscribe to services, and manage their subscriptions.

3. Smart Contracts
Smart contracts deployed on the Polygon blockchain handle subscription creation, recurring payments, and cancellation logic.

4. Blockchain Network
The Polygon blockchain records transactions securely and executes the smart contracts.

5. Service Provider Dashboard
Allows service providers to create and manage subscription plans.
