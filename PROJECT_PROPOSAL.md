2. Selected Blockchain Platform

We will implement this project using Polygon.

Polygon is a Layer-2 blockchain network designed to provide faster and cheaper transactions compared to Ethereum. It is compatible with Ethereum tools and smart contracts while significantly reducing gas fees and improving scalability.

Using Polygon allows our system to process recurring payments efficiently while maintaining the security and transparency benefits of blockchain technology.

3. Use Case / Problem Statement

Many digital services today rely on subscription models such as streaming platforms, software services, and membership-based content. These systems usually depend on centralized payment gateways that charge high transaction fees and require users to share sensitive financial information.

The proposed Blockchain-Based Recurring Payment Subscription System aims to provide a decentralized alternative where users can subscribe to services directly through crypto wallets.

In this system, service providers can create subscription plans with predefined pricing and billing cycles. Smart contracts automatically manage subscription payments on the blockchain. Transactions are recorded securely and transparently, removing the need for intermediaries and improving trust between users and service providers.

4. High-Level Architecture

The system will consist of the following components:

Frontend Application:
A web interface where users can view subscription plans, connect their crypto wallets, and manage their subscriptions.

Smart Contracts:
Subscription logic implemented as smart contracts deployed on the Polygon blockchain to automate recurring payments and record transactions.

Wallet Integration:
Users will interact with the system through crypto wallets such as MetaMask to authorize payments and manage subscriptions.

Backend (Optional):
A lightweight backend service to store off-chain metadata such as subscription details, analytics, and service provider information.

Blockchain Network:
The Polygon network will process transactions, execute smart contracts, and store subscription records securely.
